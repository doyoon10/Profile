> 말하면 자라는 성장 캐릭터

오늘 한 일을 한 줄로 적으면 AI가 어떤 스탯인지, 얼마나 어려웠는지, 몇 시간 걸렸는지 분석해 EXP로 바꿔줘요.
쌓인 EXP만큼 나만의 나무가 씨앗에서 지혜나무까지 자라고, 내가 키우는 스탯마다 나뭇가지가 뻗어나가요.

## 주요 기능
- **기록 → AI 분석**: 자연어로 쓴 활동을 스탯 · 난이도 · 소요 시간으로 분석해 EXP 지급
- **성장 캐릭터**: 레벨에 따라 씨앗 → 새싹 → 어린나무 → 큰나무 → 지혜나무로 성장
- **스탯 시스템**: 지식 · 운동 · 예술 · 라이프 카테고리 아래 원하는 스탯(리액트, 토익, 헬스 등)을 골라 키우기
- **퀘스트**: 일일 · 주간 퀘스트를 깨고 새싹코인 받기
- **성장 리포트**: 월별 EXP 추이, 연속 기록일, 스탯별 성장 확인
- **프로필**: 씨앗 상점, 꾸미기, 프로필 링크 공유
